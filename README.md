# EnglishFlow

EnglishFlow is a lightweight English learning app focused on beginner-level practice, vocabulary review, grammar basics, and lesson progression.

## Features
- Beginner-friendly A1 lesson flow
- Vocabulary cards
- Lesson quizzes
- Word review and repetition tracker
- Dashboard with progress tracking
- Built with Next.js + TypeScript + Tailwind

## Getting started

```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

## Production notes

This is an MVP demo app intended for local development and further extension. For production use, this should be connected to a real database and auth flow.
